# Evals

Test prompts with the behavior each skill must show. Run them after changing a skill: paste the prompt into a fresh session with the skills installed and check every expectation.

Each file covers one skill. An eval passes when **all** its expectations hold.

| File | Skill |
|---|---|
| [mens-color-analysis.md](mens-color-analysis.md) | Color analysis |
| [mens-style-advisor.md](mens-style-advisor.md) | Outfits from own wardrobe |
| [mens-grooming.md](mens-grooming.md) | Beard, head, skin, glasses |
| [mens-style-profile.md](mens-style-profile.md) | Profile file |
| [mens-style-book.md](mens-style-book.md) | Full style book |
| [mens-travel-packing.md](mens-travel-packing.md) | Packing list from own wardrobe |

Photo-based evals need a test photo of a consenting adult (or a stock photo licensed for this). Don't commit photos of real people to the repo.
